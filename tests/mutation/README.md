# Mutation testing

A module's input contract lives in `formal/<module>_assume.sv`: a module named `<module>_assume` whose ports carry the target's input port names and whose body holds only `assume` statements. When the file exists, `mutate.py` binds it into the unmutated copy of the equivalence miter, so both copies see the constrained inputs, and the ABC proof and the SymbiYosys fallback each honor it. A mutant that differs only on inputs the contract rules out is then counted as equivalent instead of surviving. Any module may carry one; none needs listing anywhere.

Equivalence cuts every child out of the miter, then ties to zero, in both copies, each child input bit the child never reads at the instance's parameters, so a mutant that only moves an address bit the memory ignores proves equivalent. abc runs `dprove` with interpolation off and a 240 s budget for property directed reachability. Interpolation is bounded by conflicts, not time: on boot_loader and mem_word_if mutants it ran 90 to 390 s and left reachability too little of the 480 s wall, and with it off every measured verdict was the same or better and arrived within 250 s, one of them a counterexample the default flow never reached. The mutants that stay undecided do not converge at 240 s in any engine tried (`dprove` with and without interpolation, `pdr`), so a larger budget, the SymbiYosys fallback first, or fewer and longer jobs would add time without adding verdicts; the matrix keeps one job per shard.
